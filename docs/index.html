DevSelfTrace

A Self-Annotation Tool for Understanding Programming Behavior

1North Carolina State University   2University of Oklahoma   3University of Alberta

Abstract

Understanding programming behavior in modern software development is increasingly important with the rise of artificial intelligence (AI). Despite this increased importance, researchers lack tools to capture the complex, often invisible cognitive shifts in developer programming behavior. To address this gap, we present DevSelfTrace, a general-purpose annotation tool that enables developers to retrospectively annotate their programming behavior across four key dimensions: intention, action, supporting tool, and emotion. DevSelfTrace supports flexible time segmentation, customizable labels, and exports structured logs in JSON format.

DevSelfTrace has been used by 84 developers across multiple rounds of a mixed-methods user study investigating developer-AI interaction, where the collected annotation data directly supported the behavioral analysis reported in that study. A dedicated tool evaluation survey (N=33) indicates that 66.7% of developers found DevSelfTrace easy to use, and 87.9% agreed that it could support research or education on programming behavior.

Tool Overview

DevSelfTrace is a lightweight, browser-based annotation tool that lets developers retrospectively self-annotate a screen recording of a programming session. The participant divides the recording into self-defined time intervals and annotates each interval across four dimensions, grounded in the S-IASE model from our FSE'26 paper.

Intention
What the developer is trying to achieve (e.g., To Resolve Errors).
Action
The observable activity (e.g., Writing New Code, Crafting Query/Prompt).
Supporting Tool
The tool used (e.g., AI Tools, IDE, Search Engine).
Emotion
The affective state on a 7-point valence scale.

Workflow

1 Upload a recording & set a time interval

Participants upload an MP4 screen recording of their programming session. Using a built-in video player, they navigate to a moment of interest and define a custom time interval with start/end timestamp selectors.

2 Annotate via guided dropdown menus

Each dimension comes with pre-defined options and accepts custom labels. Because intention is more abstract than the other dimensions, hovering over each intention reveals a short definition (e.g., To Design/Plan New Code → "Decide how to build something new").

3 Review & export structured JSON

A live log table shows every annotated interval and allows in-place edit or delete. When the session is done, all annotations are exported as a structured JSON file suitable for sequence mining, co-occurrence modeling, or qualitative coding.

An example of a single annotated interval in JSON format:

{
  "id": 3,
  "start": "2:33",
  "end": "3:11",
  "intention": "To Design/Plan New Code",
  "action": ["Crafting Query/Prompt"],
  "tool": ["AI Tools"],
  "emotion": "Slightly Positive"
}
